# Recorrido recomendado para presentar VPA CRM

## 1. Inicio de sesión

La primera pantalla presenta el producto y ofrece:

- **Continuar con Google**: acceso real y conexión con Calendar/Meet.
- **Ver demo local**: presentación con los datos importados de Excel, sin conexión externa.

Esto permite presentar el producto aunque Google Cloud todavía esté pendiente de configuración.

## 2. Embudo comercial

Mostrar en este orden:

1. El número total de prospectos únicos.
2. La búsqueda por empresa, teléfono, correo, contacto o ciudad.
3. **Filtros** por etapa, prioridad, industria, fuente, ubicación y seguimiento.
4. Tarjetas con color según prioridad y rojo cuando el seguimiento ya venció.
5. Arrastrar una tarjeta a otra etapa.
6. Abrir una ficha y usar **Editar prospecto**.

## 3. Agenda

Con Google configurado:

1. Abrir Agenda.
2. Ver los próximos eventos de Google Calendar.
3. Crear una reunión desde un prospecto.
4. Mostrar el enlace de Google Meet y el invitado.

## 4. Alertas y conversaciones

El cálculo de clientes descuidados ya se muestra localmente. Gmail y Google Chat se mantienen como módulos siguientes para pedir permisos separados y no mezclar el acceso al calendario con el contenido de comunicaciones.

## 5. Cierre de sesión

El botón 🚪 está en la tarjeta de cuenta de la barra lateral. Cierra la sesión Google del CRM y también permite salir del modo demo.
